# 滚动截图：产品形态与实施方案

状态：首版已实现。Luna 负责核心与界面主体，主代理完成方案、代码审查、补充生命周期测试和界面收尾。真实网页 / 应用滚动截图尚待交互验收。

## 产品定位

把网页、聊天记录、文档或应用列表的一段纵向内容截成一张长图。用户决定滚动速度、起止位置，Cutter 负责寻找重叠区域、去重、拼接和反馈。仍然是本机静态截图，不写视频、不上传、不自动保存。

采用现有原生 AppKit 控件、系统字体和操作条风格（Operate 场景）。新增入口直接可见，现有工具保留。用户已要求设计后直接交由 Luna 实现，本方案不再增加一次批准流程。

## 首版范围与取舍

选择“手动滚动、自动拼接”，不采用自动注入滚轮事件：嵌套滚动容器和页面加载时机交给用户控制，也不引入辅助功能或输入监控授权依赖。采样由截图 API 驱动，不依赖全局鼠标事件。

首版支持主显示器固定矩形区域、单方向向下滚动、多段去重拼接、可恢复的匹配失败、撤销末段、暂停、长图预览及四种现有输出。上下文工具保持可见，不能通过折叠现有标注工具腾空间。

暂不做横向或二维拼接、自动滚到底、网页 DOM 抓取、跨显示器移动跟踪、任意悬浮元素消除、长图标注。普通截图与标注维持既有行为。后续长图标注必须复用抽出的图像坐标标注模型和渲染器，不复制第二套 `RegionSelectionView`。

## 用户流程与界面

1. 用现有快捷键选区，在操作条直接点击“滚动截图”。入口是捕获模式切换，不是保存类型，不加入 `CaptureSettings.Output`。
2. 矩形、尚无标注、区域至少 120 × 120 pt 时可用。其他状态保留入口，禁用并解释：“请使用矩形选区”“请先撤销标注，再开始滚动截图”或“请扩大选区”。不静默丢弃标注、切换形状。
3. 冻结选区层关闭，恢复真实页面。保留细边框（点击穿透），小型非激活控制面板放在区域外，提示“在框内向下滚动一小段，稍停后继续”，并提醒保留上一屏的部分内容、选区避开固定页头 / 页脚。鼠标滚轮和触控板继续交给原应用。
4. 面板展示状态、`宽 × 已拼接高度 px`、有效段数、末段接缝缩略图，常显“暂停 / 继续”“撤销末段”“完成”“取消”。布局在屏幕内；实在放不下可放区域上方，但捕获过滤器必须排除 Cutter，不能截入自身面板。暂停后面板位置可拖动。
5. 第一屏准备好后显示“可以开始滚动”。每接受一段更新高度和接缝缩略图；停住时显示“等待向下滚动”，无变化不能宣称已经到底。
6. 点“完成”停止采样，先等待已在处理的有效帧结算，再进入独立长图预览窗口。预览默认适合宽度，能滚到图像最底部，提供 100% 查看；显示像素尺寸。
7. 预览常显“复制”“存储”“复制并存储”“临时贴图”及关闭。复用既有本机输出和反馈，只有点击输出才产生输出副作用。关闭预览丢弃当前结果。临时贴图保持内存内临时显示。


## 反馈与恢复规则

| 情况 | 界面和数据行为 |
| --- | --- |
| 静止、重复帧 | 不增加高度和段数；等待滚动，绝不追加重复屏 |
| 页面还在移动 / 加载 | 等待稳定，短暂显示“等待画面稳定” |
| 向上滚动或回弹 | 不追加；提示“请继续向下滚动”；保留最后接受的基准帧 |
| 一次滚太远、低纹理、重复列表匹配歧义 | 不追加；提示“暂时无法衔接，往回滚一点后慢慢继续”；完成按钮仍可用 |
| 撤销末段 | 同时回退条带、尺寸和匹配基准；提示回滚到上一段；只有首屏时禁用 |
| 固定页头 / 页脚 | 首版要求选区避开；匹配歧义时拒绝追加，但尚未实现通用固定边带检测或自动消除，不应依赖它来移除吸顶元素 |
| 捕获权限失效、显示器变化、尺寸或比例改变 | 停止采样，说明原因；已有结果可完成预览；无首屏则只能重试或取消 |
| 达到尺寸 / 内存上限 | 停止追加并提示“已达到本次长图上限，可完成保存”；保留有效结果 |
| 完成 / 取消竞态、退出应用 | 结果只提交一次，停止后台任务，关闭所有会话面板；不遗留捕获任务 |

状态不能仅靠颜色表达。面板按钮有 VoiceOver 标签、键盘焦点和提示。原应用拥有键盘焦点时不劫持普通 Return/Esc；面板拥有焦点时 Return 完成、Esc 取消。全局截图快捷键在会话中应给出明确状态或取消行为，不能并发启动另一截图。

## 技术方案与职责

Apple 文档确认 `SCScreenshotManager.captureImage` 接受内容过滤器和配置；`SCContentFilter` 支持排除应用。复用 macOS 14 API，不使用更新系统才支持的截图接口。

- API 依据：[SCContentFilter](https://developer.apple.com/documentation/screencapturekit/sccontentfilter)、[SCScreenshotManager](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager)。
- **捕获来源**：新增区域采样会话或等价的窄接口，固定 displayID、区域、像素比例、过滤器；配置不捕获鼠标、不捕获音频，排除 Cutter 全部窗口。不要每帧枚举全部窗口。首屏必须来自恢复实时页面后的新采样，不能混用原来带冻结选区的图像。
- **坐标**：请求携带显示器局部 AppKit 点坐标，捕获边界统一转换为图像左上原点物理像素，裁剪须在范围内。全局屏幕原点、Retina 倍率仅在平台边界处理。用独立测试证明纵向方向和倍率。
- **`ScrollCaptureSession`**：协调准备、采样、稳定检测、暂停、恢复、撤销、完成、取消和资源释放；UI 接收明确状态与进度，不接触匹配阈值。连续调用截图 API（建议约 250–350ms 一次）即可；一次只允许一个采样 / 处理流水线，工作队列无积压。
- **`VerticalImageStitcher`**：独立于 AppKit、权限和窗口。输入规范化图像，返回追加 / 重复 / 反向 / 匹配不足 / 达到上限等结果，内部隐藏重叠搜索、置信度和条带存储。处理不放 MainActor。
- **捕获 HUD / 结果预览**：独立窗口控制器；UI 只调用会话动作。预览用原生 `NSScrollView` 或等价，必须支持真实长图而非缩成一条不能查看。
- **集成**：选区完成结果用明确枚举区分普通图像输出与滚动请求（或同等清楚的类型）；避免用空图像和伪造 Output 传递控制信号。`AppDelegate` 保持流程调度，提取公用输出方法供普通截图和长图复用。

### 匹配与合成

使用像素重叠匹配，不使用 OCR 或语言模型。先在降采样亮度 / 梯度图上估计竖向位移，再在全分辨率邻域验证。可接受向下位移的基准是旧帧下方与新帧上方重合，输出追加新帧的底部新内容。

匹配必须同时考虑有效重叠量（建议至少 25%）、多个横向内容带的支持、误差以及最优和次优候选的区分度。避免把大片空白或重复表格当可靠证据。比较多个候选位移，不能取第一个通过阈值的候选。静态页头不能主导零位移；不支持的运动应拒绝而不是猜。

稳定检测比较相邻采样，不改变最后成功帧；匹配失败时基准保持不变，用户回滚后可恢复。重复判断与反向识别不产生输出条带。固定浮层明显破坏一致运动时，优先拒绝并提示调整选区。

最终合成只绘制一次，保留原始像素分辨率；实时预览使用有界缩略图。不要每追加一屏都分配一张越来越高的完整图像。条带需独立紧凑存储，避免 `CGImage.cropping` 的共享底层内存意外保留整帧。

首版设置明确上限：最大输出高度 32,768 px、最大输出 40,000,000 像素，并限制会话内存预算（建议不超过 384 MiB，需计入基准帧、条带、匹配缓冲及最终画布 / 导出峰值）。实际以内存预算更早触发者为准；乘法和分配前检查溢出。超限不破坏已有结果。

## 验收要求

- 普通截图的工具、形状、尺寸、复制 / 保存 / 贴图均可继续使用。
- 合成测试从已知长图裁出含不等位移的多帧，拼接后的尺寸和像素与原图对应区段一致；覆盖 1x / 2x、首屏、重复帧、反向、缺失重叠、低纹理 / 重复内容、撤销再接续、上限。
- 失败样本断言不改变有效结果，不只测试“函数返回成功”。覆盖取消发生在异步捕获期间、完成与回调相遇的生命周期行为。
- 运行 SwiftPM 构建、直接编译与 `.app` 打包；新增文件写入 `scripts/build-dev.sh`。合成测试使用能在当前机器执行的 Swift 测试或独立 harness，并保存可重复运行的脚本。
- 对真实 AppKit HUD / 长图预览做受控渲染，检查按钮、焦点、缩放和到底部访问。机械 Web 设计扫描不作为 Swift UI 验收证据。
- 如果系统授权允许，用一个含文本、图片、重复行的可控原生滚动视图验证屏幕采样到长图输出的实际链路，检查 Cutter 控件没有进入图片；若权限阻塞，应明确报告，不能把合成算法测试描述成真实截图成功。
- 更新 README、PRODUCT 和 ARCHITECTURE 的功能状态，修正文档中已经实现的贴图 / 窗口截图仍列为未实现的过时条目。构建后用项目脚本重启并确认进程。做一次独立功能提交，不推送、不重写历史。

## 交付分工

主代理负责产品方案、文档和最终结果审查。Luna 负责首版代码、可重复算法 / 生命周期验证、受控 UI 验证、构建与重启；发现实现与本方案冲突时先报告具体原因，不能自行把自动拼接降为手动逐屏无重叠拼接。主代理在 Luna 工作期间审查集成和验收边界，不同时编辑其源文件。
